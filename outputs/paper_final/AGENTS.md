# Results 中英文同步维护

以下规则落实用户要求：“维护一个results部分的翻译文件，每当修改时你都需要同步修改翻译内容”。

## 唯一维护入口

以下 Results 标题以用户于2026年11月16日确认的版本及随后对2.2用语的调整为准。正文润色、翻译和文件同步时保留，不因历史快照或派生稿中的不同写法而替换：

- 2.1 国际流动的总体均衡化掩盖了国家份额增长的集中
- 2.2 新增记录城市推动国内城市流动的集中化
- 2.3 跨尺度的流动分布反差在四大学科中普遍存在，社会科学最为突出

- `results.tex` 是 Results 英文源文件，直接在原文件中修改。
- `results_zh.md` 是持续维护的 Results 中文译稿，覆盖全部小节标题、正文和图注，顺序与英文一致。
- `figures/` 按整图保存论文插图。子图统一排在所属整图中，排版检查文件放在论文插图目录之外。
- `outputs/results_rewrite_20261111/` 等日期目录中的译稿属于历史快照，不作为后续修改入口。不得用历史生成脚本覆盖当前英文稿或中文译稿。

## 每次修改的同步要求

1. 修改 `results.tex` 时，在同一任务中同步修改 `results_zh.md` 对应内容。包括标题、论述、数据、单位、T1–T4定义、样本范围、图注、引用及补充材料指向。不能只更新日期或源文件哈希而不翻译实质变化。
2. 如果方法、图表、补充材料或参考文献的变化影响 Results 的表述或编号，同时检查并更新中英文对应内容。
3. 按段核对数字、正负号、百分比与百分点、年份、国家与城市样本数量、组别边界和统计口径，保持论断强度一致。
4. Results 的公式已移至 `methods.tex`。中文 Results 保留与英文一致的文字定义，不将方法公式重新加入译稿。
5. 完成翻译和核对后，将 `results_zh.md` 文件头的 `source_sha256` 更新为当前 `results.tex` 原始字节的 SHA-256，并更新 `last_synced`。哈希用于判断是否过期，不能代替语义核对。纯排版修改也应核对译稿并更新哈希。
6. 修改英文 LaTeX 后，遵循当前编辑器工作流，使用内置 `compile_latex_document` 编译原项目；只修改中文 Markdown 时无需编译。除非用户另有要求，不另建替代 LaTeX 文稿、独立预览 PDF 或打开其他编辑标签页。
7. 完成反馈时提供持续维护的 `results_zh.md` 链接，不再另建日期命名的译稿作为交付入口。

## 翻译术语与解释边界

| 英文概念 | 中文固定表述或要求 |
| --- | --- |
| international mobility / domestic mobility | 国际流动 / 国内流动 |
| concentration | 集中化。国内集中化以 Gini 拟合趋势上升且等效城市数占比拟合趋势下降判定。保留等效城市数增加、HHI 下降可以与这一变化并存的解释。 |
| newly recorded cities | 新增记录城市；指1998年后首次被记录，不解释为新建城市 |
| continuously recorded cities | 持续记录城市；不直接等同于城市间内部连边组成的子网络 |
| normalized equivalent city count | 归一化等效城市占比；与绝对等效城市数区分 |
| combined domestic city strength | 国内城市流入与流出总量 |
| physical / life / health / social sciences | 物理科学 / 生命科学 / 健康科学 / 社会科学 |
| positive endpoint share changes | 期末相较期初为正的国家份额变化；与组别净变化及去集中化贡献区分 |

第一节以T1–T4增长梯度和组别规模差异为主，避免重新加入大量具体国家例子。分组使用未经四舍五入的中位数；展示的近似阈值不能代替实际分组边界。表达应延续用户偏好，不使用“份额增益”或“追赶”。
