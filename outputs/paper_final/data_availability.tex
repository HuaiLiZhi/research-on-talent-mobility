\section*{Data Availability}

The OpenAlex bibliographic metadata used in this study are publicly available. The country-year, city-year, origin--destination (OD) pair--year, and field-year aggregated data supporting the conclusions of this study, together with the source data for each main figure, will be deposited in a permanent public repository upon publication. The repository URL and DOI will be added here: [repository URL/DOI]. To reduce the risk of re-identification from individual trajectories, the original author-year-level trajectories will not be made public.
